# Customer-Churn-Prediction
Customer Churn Prediction 📉

📌 Project Overview

This project focuses on predicting customer churn using machine learning. Customer churn occurs when customers stop using a company's products or services. The goal is to explore customer data, identify patterns, and build a model to predict potential churn.

🎯 Project Objectives

Explore customer data and identify important features.

Clean and preprocess the dataset.

Perform Exploratory Data Analysis (EDA).

Analyze factors associated with customer churn.

Train a machine learning classification model.

Evaluate model performance using appropriate metrics.

📊 Model Evaluation

The model should be evaluated using:

Accuracy

Precision

Recall

F1-score

Confusion Matrix

Important: Accuracy alone may be misleading when churn and non-churn customers are imbalanced. Recall and F1-score for the churn class are also important.
